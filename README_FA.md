# هاشم AI — پروژهٔ نمونهٔ ویرایش عکس

این فایل ZIP کد اولیهٔ سایت است، نه سایت آنلاین یا اپلیکیشن نصب‌شدنی.

## اجرا روی سرور Node.js
1. فایل ZIP را استخراج کنید.
2. در پوشه پروژه `npm install` اجرا کنید.
3. کلید API را فقط در متغیر محیطی سرور با نام `OPENAI_API_KEY` تنظیم کنید؛ هرگز آن را در HTML یا چت قرار ندهید.
4. `npm start` اجرا کنید.
5. برنامه روی پورت 3000 (یا PORT تعیین‌شده توسط میزبان) اجرا می‌شود.

API رسمی ممکن است هزینه داشته باشد و از اشتراک ChatGPT جداست. دسترسی و قیمت سرویس را پیش از فعال‌سازی بررسی کنید. برای سایت عمومی، محدودیت درخواست، احراز هویت و سقف هزینه اضافه کنید. حفظ کامل هویت چهره تضمین‌پذیر نیست.
